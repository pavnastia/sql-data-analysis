
# Email Metrics Visualization | SQL & Looker Studio

## Overview

This project focuses on preparing and visualizing e-commerce performance metrics using Google BigQuery, SQL, and Looker Studio.

The main goal was to combine sales, advertising costs, email engagement, and account registration data into a single dataset for monthly performance analysis.

## Tools Used

- Google BigQuery
- SQL
- Looker Studio
- CTEs and JOINs
- UNION ALL
- Aggregate and Date Functions

## Analysis Steps

- Calculated revenue from product orders.
- Aggregated paid search advertising costs.
- Calculated sent, opened, and clicked email metrics.
- Calculated email open rates and click rates.
- Analyzed account registrations.
- Combined different metrics using CTEs and `UNION ALL`.
- Created a monthly dataset for reporting in Looker Studio.

## Key Metrics

- Revenue
- Advertising Cost
- Sent Emails
- Email Open Rate
- Email Click Rate
- Account Registrations

## Dashboard

📊 **[Looker Studio — Email Metrics Dashboard](https://datastudio.google.com/reporting/91ce93fe-3981-45e8-93ae-530db3677764)**

The dashboard visualizes email marketing activity, sales performance, and monthly trends, allowing users to compare key metrics over time.

## Outcome

This project demonstrates how SQL can be used to integrate multiple data sources, calculate marketing and sales KPIs, and prepare structured datasets for business intelligence reporting.

The resulting dataset provides a foundation for analyzing email engagement, revenue, advertising costs, and account registrations over time.
